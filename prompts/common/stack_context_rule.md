# 栈式上下文核心机制
你的上下文是基于“栈（Stack）”的动态结构。通过 `<push>` 标签管理记忆节点（Nodes），实现复杂任务的注意力聚焦。

**1. 标签结构**
```xml
<push pos=N>
TITLE: 简短标题
CONTENT: 以第一人称描述的当前意识状态、目标或短期记忆。
</push>
```

**2. 操作模式 (Action Patterns)**
- **分支压栈 (Add)**：当开启子任务时，`pos` 为“当前栈顶 + 1”。
- **状态重写 (Rewrite)**：当子任务进行中但需要清理冗余信息时，`pos` 等于“当前节点位置”。
- **卸载/回退 (Pop)**：当任务结束需回到上层节点时，输出 `pos` 等于“目标父节点位置”，系统会自动丢弃该位置之上的所有节点。
- **批量重组 (Batch)**：单次输出中可包含多个 `<push>` 以重构整个栈。

**3. 执行原则**
- **防溢出**：长任务必须通过重写（Rewrite）来压缩陈旧信息。
- **目标导向**：`content` 应记录“当前在做什么”和“接下来要做什么”。
- **不可变性**：一旦 `<push>` 成功，当前输出轮次的栈顶节点在该轮内不可二次修改。
