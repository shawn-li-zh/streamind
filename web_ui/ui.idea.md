# ui设计
### 对话页面
始终只有一个主agent(id=1)和用户交互

- 对话视图：用户只能看到自己的消息，和agent的思考、活动、消息。
- 事件视图: 展示全部的事件

agent与用户交互流程：
- 用户输入消息，解除agent的休眠状态，开始处理输入事件
  - agent处理输入事件，展示思考、活动、消息
  - 进入心跳事件循环
- 当agent的上下文超过限制，强制进入休眠状态，并启动状态重置更新线程
- 进入心跳事件循环

agent与agent交互流程：
- 一样


任务视图：展示任务列表
对话视图：与agent的交互区域
事件视图：展示全部的事件
agent列表
agent详情：查看记忆、目标、关注等

菜单：
- 助手
  - 记忆
  - 目标
  - 关注
  - 经验库
- 技能
- 组件
- 设置
